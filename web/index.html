怎么用

  • 一键整洁（顶栏按钮 / T）：把整面重新排成标准树
  • 拖动节点：拖到哪停哪，松手不回弹
  • ＋：在当前卡片下挂一个子节点
  • 双击卡片：编辑；双击空白：新建（挂到最近的节点）
  • 把卡片拖到另一张卡片上：改挂父级
  • Delete：删除选中节点（子节点自动上挂）
  • 滚轮：以光标为锚缩放；拖空白：平移
  • ⌘⇧L：切换深色 / 纸感浅色主题
  • H：返回首页 / 打开图库

网页版不保存任何内容：刷新或关掉标签页即全部忘记。下载桌面版才会记住你上次编辑的那幅图和视角。
